How Deployment Works

⚡ Fully Automatic Deployment

Every time you save or delete a project in this admin, the change is committed directly to GitHub. GitHub Actions automatically builds and deploys the site — no manual steps needed.

Typically live within 2–3 minutes of saving.

Deployment Flow

1

You save a project

Admin commits the change to data/projects.json on GitHub via the API.

2

GitHub Actions triggers

The push automatically starts the build workflow (deploy.yml).

3

Next.js builds the site

GitHub Actions runs npm run build — reads the updated JSON.

4

Live on GitHub Pages

The new static export deploys. Visit the live site ↗ or check GitHub Actions ↗.
